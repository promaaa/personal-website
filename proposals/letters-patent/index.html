(57) Abstract

An engineer comprising a training in robotics and embedded systems, a master’s degree in progress in 3D vision, and a research internship in 5G and efficient vision models, configured to turn complex physical problems into deterministic hardware with clean software abstractions. The engineer further comprises a writing practice and a reading habit.

Résumé : Un ingénieur comprenant une formation en robotique et systèmes embarqués, un master en cours en vision 3D et un stage de recherche en 5G et en modèles de vision efficaces, configuré pour transformer des problèmes physiques complexes en matériel déterministe doté d’abstractions logicielles propres.

Detailed description Machines, systems & prototypes.

  1. First embodiment: an autonomous ball-collecting robot

    Guidance is by optical bearing. The DC motor’s transfer function is identified as a first-order system, and cascaded PI loops on speed and heading position the robot within ±0.5–1 cm.

    Source code

  2. Second embodiment: SmartChess

    A 64-reed sensor matrix reads the board; a PyTorch CNN tracks its corners; an embedded engine, IA-Marc V2, plays on a Raspberry Pi 5. Build photographs and CAD are disclosed.

    Source code Video demonstration

  3. Third embodiment: Nand2cpu, a 16-bit ALU

    An arithmetic logic unit built from first principles in Verilog, verified by an automated testbench (7 + 8 = 15), and accompanied by an assembler.

    Source code Video demonstration

  4. Fourth embodiment: an OAI 5G CU–DU split

    An OpenAirInterface split DU runs on a Jetson Orin Nano and a Raspberry Pi 5 to form lightweight UAV cells, with Ethernet, Wi-Fi or 5G backhaul. A paper was submitted in 2026.

    Source code Submitted paper (PDF)

  5. Fifth embodiment: Evento

    Wallet-based ticketing on Solana Pay, built under hackathon constraints, keeping a clean boundary between on-chain and off-chain state, with sub-second finality.

    Source code

Background Built through theory. Tested in practice.

  1. The inventor is a robotics and embedded systems engineer and a master’s student in the 3D Vision Lab at Seoul National University. Previously, the inventor was a research intern at KAUST, in the SeRBER lab, working on efficient vision models, NVIDIA Jetson deployment and a 5G testbed for UAV relay cells.

  2. The inventor’s background spans autonomous robotics, closed-loop control, custom PCB layout and real-time firmware. Tools in regular use include STM32 and ESP32, embedded C and C++, FreeRTOS, Altium and KiCad, Verilog and FPGAs, CAN, SPI and I²C, PID control and kinematics, and OpenCV.
